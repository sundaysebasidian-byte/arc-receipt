# Manual transaction review hypothesis — no user study conducted

Hypothesis: an independent reviewer may benefit from a fixed-address incoming/outgoing/net view and an evidence package that states its comparison basis and can be rechecked later. This is not verified demand, adoption or a merchant nonpayment finding. Official Explorer already decodes transfers and provides State changes.

Four technical cases have been genuinely reproduced locally; see workflow-comparison.md and evidence/workflows/acceptance.json. Those automated controls and requests are not human task times or evidence of saved time.

A later consenting reviewer exercise could ask participants to identify the selected address's three amounts, explain what100.010001 compares against, interpret the normal Swap intermediary without calling an invoice unpaid, and hand off/reimport evidence while naming its trust limits. Ask them to repeat the same questions using official Explorer. Record actual completion, assistance, time and exact comments only with consent. Do not send invitations or use personal transactions without authorization.

Use pseudonyms and public samples; do not collect account balances, wallet secrets, legal identity or customer invoices. The CSV remains empty apart from headers. Confusion about gross receipts versus net, sweep destinations, partial allocations, mint exclusions or unsigned single-provider observations is a defect to resolve before claiming usefulness. No performed interviews, task-time benefit or grant outcome is stated.
