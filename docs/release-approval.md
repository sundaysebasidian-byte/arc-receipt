The demonstration observes existing third-party public transactions. They are not builder transactions, customer bills, user income or grant proceeds. Order demo IDs/totals are illustrative local assignments, not verified invoices.

The [official event/FAQ](https://community.arc.io/public/events/arc-microgrants-f8tijfjhyq) requires a deployed, working mainnet project but does not explicitly settle whether a hosted read-only app without a custom contract or builder-originated transaction qualifies. Hosting alone must not be described as organizer acceptance. The app's read-only design is a product choice, not a verified rule limiting all entries.

Official consultation route: [Build on Arc Discord](https://discord.com/invite/buildonarc). Unsent question: “Does a publicly hosted read-only Arc-mainnet receipt/USDC verifier, without a custom contract or builder-originated transaction, meet the deployed-and-working-mainnet requirement; if not, what minimum on-chain component is required?” No organizer contact or grant application is included in this release.

An application still needs a separate review of eligibility, submission rights, previous program funding, actual application/payout terms and receiving arrangements. No financial account or payout wallet is created or inferred by this project.
